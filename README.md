# Vigenere Cipher

Aplikasi enkripsi dan dekripsi **Vigenere Cipher** berbasis GUI, dibuat dengan Python dan Tkinter.

## Tentang Vigenere Cipher
Vigenere Cipher adalah cipher polialfabetik. Kuncinya berupa kata yang diulang sepanjang teks. Setiap huruf kunci menentukan besar pergeseran huruf pada teks di posisi yang sama (A = 0, B = 1, ..., Z = 25). Karena pergeserannya berbeda-beda, cipher ini lebih sulit dipecahkan dibanding Caesar Cipher.

## Fitur
- Enkripsi dan dekripsi teks
- Kunci berupa kata (huruf saja)
- Tampilan aliran kunci yang sejajar dengan teks asli
- Tombol salin hasil ke clipboard
- Huruf besar/kecil dan tanda baca tetap dipertahankan

## Cara Menjalankan
Pastikan Python 3 sudah terpasang (Tkinter sudah termasuk di Python).
